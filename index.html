Speed Normal

Array Visualization

Array elements contiguous memory me store hote hain. Index se direct access O(1) hai, insert/delete me shifting ki wajah se O(n).

Stack Visualization

Stack LIFO (Last In, First Out) follow karta hai. Push aur pop sirf TOP pe hote hain, top pointer move hota dikhega.

Queue Visualization

Queue FIFO (First In, First Out) follow karta hai. Enqueue REAR pe, dequeue FRONT se hota hai.

Linked List Visualization

Har node me data aur next ka address hota hai. Memory dynamic use hoti hai, traversal HEAD se start hota hai.

Tree Visualization (Binary Search Tree)

Hierarchical data parent-child relation ke saath. BST me left child chhota aur right child bada hota hai. Inorder, Preorder aur Postorder traversal animate hote hain.

Graph Visualization

Graph nodes ke beech connections dikhata hai. BFS queue use karta hai (level by level), DFS stack/recursion use karta hai (deep first). Neighbours alphabetical order me visit hote hain.
