# Data Structure Visualizer

**Live Demo:** https://nujhatshaikh.github.io/data-structure-visualizer/

Interactive web app jo data structures ko step-by-step animation ke saath samjhata hai.
Pure HTML, CSS aur JavaScript, koi framework ya installation nahi chahiye.

## Features
- **Array**: insert, delete, search, access, traverse
- **Stack**: push, pop, peek (LIFO) with TOP pointer
- **Queue**: enqueue, dequeue, peek (FIFO) with FRONT/REAR
- **Linked List**: insert (head/tail/position), delete, search, traverse
- **Tree (BST)**: insert, delete, search, Inorder / Preorder / Postorder
- **Graph**: BFS and DFS animations, custom edges
- Adjustable animation speed and live step-by-step log

## Run locally
`index.html` ko browser me open karo, ya VS Code me **Live Server** extension se *Go Live* karo.
